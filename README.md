# ReguShield AI

Frontend MVP shell for an agentic cyber governance dashboard for banks.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
```

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui-style components
- Radix UI primitives
- Lucide React icons

## Current Scope

- Mock data only
- No backend
- No authentication
- Polished dashboard shell with upload, MAP tasks, evidence validation, risk monitoring, and recent activity sections
